## go_router

`go_router` 是 Flutter 官方推荐的路由管理库，提供声明式路由（declarative routing）配置，支持 Web URL、Deep Link、嵌套路由等特性。
### 一、基本使用

#### 1.1 创建并注册路由

```dart
import 'package:go_router/go_router.dart';

final GoRouter router = GoRouter(
  initialLocation: '/',
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => HomePage(),
    ),
    GoRoute(
      path: '/detail',
      builder: (context, state) => DetailPage(),
    ),
    GoRoute(
      path: '/profile',
      builder: (context, state) => ProfilePage(),
    ),
  ],
);

void main() {
  runApp(MyApp());
}

class MyApp extends StatelessWidget {
  @override
  Widget build(BuildContext context) {
    return MaterialApp.router(
      title: 'My App',
      routerConfig: router,
    );
  }
}
```

#### 1.2 页面跳转

```dart
// 跳转到新页面（替换当前路由栈）
context.go('/detail');

// 压栈（可以返回）
context.push('/detail');

// 返回
context.pop();

// 返回并传值
context.pop('result data');

// 替换当前页面
context.replace('/detail');
```
### 二、参数传递

#### 2.1 路径参数 (Path Parameters)

```dart
// 路由配置
GoRoute(
  path: '/user/:id',
  builder: (context, state) {
    final id = state.pathParameters['id'];
    return UserPage(id: id!);
  },
),

// 跳转
context.go('/user/123');
```

#### 2.2 查询参数 (Query Parameters)

```dart
// 路由配置
GoRoute(
  path: '/search',
  builder: (context, state) {
    final keyword = state.uri.queryParameters['keyword'];
    final page = state.uri.queryParameters['page'];
    return SearchPage(keyword: keyword, page: page);
  },
),

// 跳转
context.go('/search?keyword=flutter&page=1');
```

#### 2.3 对象传参 (Extra)

```dart
// 定义数据模型
class UserModel {
  final String id;
  final String name;
  UserModel({required this.id, required this.name});
}

// 路由配置
GoRoute(
  path: '/user/detail',
  builder: (context, state) {
    final user = state.extra as UserModel;
    return UserDetailPage(user: user);
  },
),

// 跳转
context.push(
  '/user/detail',
  extra: UserModel(id: '123', name: 'Tom'),
);
```

#### 2.4 接收 pop 返回值

```dart
// 等待返回值
final result = await context.push('/edit');
if (result != null) {
  print('返回值: $result');
}

// 返回时传值
context.pop('success');
```
### 三、嵌套路由

#### 3.1 子路由

```dart
GoRoute(
  path: '/home',
  builder: (context, state) => HomePage(),
  routes: [
    // 子路由
    GoRoute(
      path: 'detail',        // 注意：子路由不需要加 /
      builder: (context, state) => DetailPage(),
      routes: [
        // 孙路由
        GoRoute(
          path: 'info',
          builder: (context, state) => InfoPage(),
        ),
      ],
    ),
  ],
),

// 完整路径
// /home
// /home/detail
// /home/detail/info
```

#### 3.2 ShellRoute（底部导航栏）

```dart
final GoRouter router = GoRouter(
  routes: [
    ShellRoute(
      builder: (context, state, child) {
        return ScaffoldWithNavBar(child: child);
      },
      routes: [
        GoRoute(
          path: '/home',
          builder: (context, state) => HomePage(),
        ),
        GoRoute(
          path: '/explore',
          builder: (context, state) => ExplorePage(),
        ),
        GoRoute(
          path: '/profile',
          builder: (context, state) => ProfilePage(),
        ),
      ],
    ),
  ],
);

// 底部导航栏组件
class ScaffoldWithNavBar extends StatelessWidget {
  final Widget child;
  const ScaffoldWithNavBar({required this.child});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: child,
      bottomNavigationBar: BottomNavigationBar(
        currentIndex: _getSelectedIndex(context),
        onTap: (index) => _onTap(context, index),
        items: [
          BottomNavigationBarItem(icon: Icon(Icons.home), label: '首页'),
          BottomNavigationBarItem(icon: Icon(Icons.explore), label: '发现'),
          BottomNavigationBarItem(icon: Icon(Icons.person), label: '我的'),
        ],
      ),
    );
  }

  int _getSelectedIndex(BuildContext context) {
    final location = GoRouterState.of(context).uri.toString();
    if (location.startsWith('/home')) return 0;
    if (location.startsWith('/explore')) return 1;
    if (location.startsWith('/profile')) return 2;
    return 0;
  }

  void _onTap(BuildContext context, int index) {
    switch (index) {
      case 0: context.go('/home'); break;
      case 1: context.go('/explore'); break;
      case 2: context.go('/profile'); break;
    }
  }
}
```
### 四、路由守卫（重定向）

#### 4.1 全局重定向

```dart
final GoRouter router = GoRouter(
  initialLocation: '/',
  redirect: (context, state) {
    final isLoggedIn = AuthService.isLoggedIn;
    final isLoginPage = state.matchedLocation == '/login';

    // 未登录且不在登录页 -> 跳转登录
    if (!isLoggedIn && !isLoginPage) return '/login';

    // 已登录且在登录页 -> 跳转首页
    if (isLoggedIn && isLoginPage) return '/home';

    // 不重定向
    return null;
  },
  routes: [...],
);
```

#### 4.2 单个路由重定向

```dart
GoRoute(
  path: '/admin',
  redirect: (context, state) {
    // 非管理员不能访问
    if (!AuthService.isAdmin) return '/home';
    return null;
  },
  builder: (context, state) => AdminPage(),
),
```

GoRoute(

### 六、错误处理

#### 6.1 404 页面

```dart
final GoRouter router = GoRouter(
  errorBuilder: (context, state) => ErrorPage(
    error: state.error,
  ),
  routes: [...],
);

// 404 页面
class ErrorPage extends StatelessWidget {
  final Exception? error;
  const ErrorPage({this.error});

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: Center(
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          children: [
            Text('页面不存在', style: TextStyle(fontSize: 24)),
            SizedBox(height: 16),
            ElevatedButton(
              onPressed: () => context.go('/'),
              child: Text('返回首页'),
            ),
          ],
        ),
      ),
    );
  }
}
```


### 七、监听路由变化

```dart
final GoRouter router = GoRouter(
  observers: [MyRouteObserver()],  // 路由观察者
  routes: [...],
);

// 自定义观察者
class MyRouteObserver extends NavigatorObserver {
  @override
  void didPush(Route route, Route? previousRoute) {
    print('进入: ${route.settings.name}');
  }

  @override
  void didPop(Route route, Route? previousRoute) {
    print('返回: ${previousRoute?.settings.name}');
  }
}
```

### 八、常用 API

#### 跳转
| 方法 | 说明 |
|------|------|
| `context.go('/path')` | 跳转（清空栈） |
| `context.push('/path')` | 压栈（可返回） |
| `context.replace('/path')` | 替换当前页 |
| `context.pop()` | 返回上一页 |
| `context.pop(result)` | 返回并传值 |
| `context.pushReplacement('/path')` | 压栈并替换 |

#### 状态获取
| 方法 | 说明 |
|------|------|
| `GoRouterState.of(context)` | 获取当前路由状态 |
| `state.uri` | 当前 URI |
| `state.pathParameters` | 路径参数 |
| `state.uri.queryParameters` | 查询参数 |
| `state.extra` | 额外参数 |
| `state.pageKey` | 页面 Key |

#### 判断
| 方法 | 说明 |
|------|------|
| `context.canPop()` | 是否可以返回 |
| `router.canPop()` | 全局判断是否可以返回 |
